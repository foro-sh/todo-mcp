# Priority rubric

| Priority | Use it for |
| --- | --- |
| `high` | Has a deadline in the next two days, or blocks someone else |
| `medium` | Should happen this week; the default for anything unclear |
| `low` | Nice to have, no date attached |

If more than a third of open tasks are `high`, the rubric is not being
applied. Push the least urgent ones down a level and say so.
